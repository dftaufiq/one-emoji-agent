A small Python program that writes a single emoji, U+1F47E ALIEN MONSTER (👾), to /output/entry.txt. The glyph never changes — every run produces the same single character. It stands for jon, a background build agent: a little digital creature that lives inside machines, works while its owner sleeps, and builds and submits code on their behalf — instantly readable, specific to how the agent works, and far from the obvious robot or smiley.

## Run it

Run the script from the repo root — it validates the glyph, then writes it to /output/entry.txt:

```sh
python3 main.py
```
